# InfiniteLoopAttacker
Test vibe code Game🤣

## วิธีเล่น
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## Vibe Code Prompt
Prompt ที่ใช้สั่ง AI เขียนเกมนี้ (ไฟล์เดียวจบ):

```
เขียนเกมเว็บไฟล์เดียว index.html ห้ามใช้ library ภายนอก ใช้แค่ HTML5 Canvas + JavaScript ธรรมดา เน้นใช้ทรัพยากรคุ้มที่สุด

- ชื่อเกม Infinite Loop Attacker ขนาดจอ 400x600 อยู่กลางจอ HUD ทั้งหมดต้องอยู่ในกรอบเกม
- หน้า Title: ชื่อเกม + "Destroy the bug invasion!" + ปุ่ม Start + เวอร์ชัน v1.0.1 มุมขวาล่าง (ห้ามโชว์ Level)
- กด Start: โชว์ "Level: N" กลางจอ 2 วินาที แล้วค่อยเริ่มเล่น จากนั้น Level ไป dock อยู่กลางบน
- บังคับ: Arrow Left/Right = เดิน, Spacebar = ยิง (คูลดาวน์สูงสุด 250ms กันยิงเป็นเลเซอร์), Esc = หยุดเกม
- ศัตรู 4 แบบ: NORMAL (ชมพู ยิงเดี่ยว), FAST (ส้ม ยิงเร็ว), SPREAD (ม่วง ยิงทีละ 3 ลูก), BOSS (ทอง ยิงเร็ว+3 ลูก โอกาสเกิด 15%)
- ศัตรูขยับซ้ายขวา ตัวริมสุดชนขอบจอเมื่อไรให้ลงล่างเท่าความสูง 1 ตัวแล้วกลับทิศ ห้ามทะลุขอบ ความเร็วเพิ่มตามด่าน จำนวนสูงสุด 8 แถว x 8 คอลัมน์
- ด่านไม่จำกัด ยิงหมดด่านให้ขึ้นจอ Level ถัดไปกลางจอ 2 วิ แล้วเริ่มเวฟใหม่พร้อมรีเซ็ตตำแหน่งผู้เล่นกลับกึ่งกลาง
- ชีวิต 3 ชีวิต โดนกระสุนให้ตัวกระพริบพร้อมอมตะ 1 วินาทีกันโดนซ้ำ
- คะแนนตัวละ 100 เก็บ High Score ลง localStorage key infiniteLoopAttackerHighScore
- โชว์ FPS มุมขวาล่าง ล็อก 60fps
- กด Esc หยุดเกม โชว์ PAUSE กลางจอ มีปุ่ม Resume กับ Return to Title (ปุ่มหลังทิ้งคะแนนของด่านที่เล่นค้างไว้)
- หน้า Game Over สรุป: Final Score, High Score, Level, จำนวนนัดที่ยิง, ยิงโดน, ความแม่น%, จำนวนฆ่าแยก 4 ประเภท มีปุ่ม Play Again กับ Back to Title (เก็บคะแนนปกติ) พร้อมเครดิต "Vibe Code by Erdnalf" และ "Model : Muse Spark 1.3 Free"
- ใต้เกมมีแถว How to play และจำนวนชีวิต
- ห้ามใช้คำว่า alien / Space Invader (เลี่ยงลิขสิทธิ์) ให้ใช้คำว่า bug แทนทั้งหมด
```
